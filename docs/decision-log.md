## 진행 기록

- 2026-09-14: 사용자 요청에 따라 문서 변경을 main에 먼저 반영하고 실제 구현은 별도 기능 브랜치에서 진행한다. 첫 구현 브랜치는 feat/app-shell-theme이며, main에서 작성된 미커밋 구현 변경은 해당 브랜치로 이동한다.

- 2026-09-14: 사용자가 상세 설계의 나머지 방향을 수용하고 이메일 인증을 카카오 로그인으로 변경 요청. Mermaid를 Excalidraw 편집 원본과 SVG 미리보기로 교체. 영상 속 도구명은 확인되지 않아 Excalidraw를 대안으로 선택. 기능 코드는 변경하지 않음.

- 2026-09-14: 화면·데이터·권한·AI 저장 계약과 단계별 구현/검증 계획을 docs/design.md에 작성. 환불·탈퇴 등 남은 정책은 권고로 구분. 기능 코드 및 DB 배포 변경 없음.

- 2026-09-14: 사용자 초안 검토 완료. GitHub 저장소를 https://github.com/Wooyongjeong/smart-budget 으로, 기본 브랜치를 main으로 지정. 기능 구현은 아직 시작하지 않음.

- 2026-09-14: Inception 전에 Flutter 기본 프로젝트와 패키지가 생성됨. 기능 변경 패치는 적용 실패하여 기능 구현은 반영되지 않음. 사용자가 AI-DLC 절차를 지적하여 구현 중단.
- 2026-09-14: 요구사항·흐름·금액 규칙·검증 기준·미결정 정책을 Inception 초안으로 작성. 사용자 검토 전이며 Construction 진입 전.
